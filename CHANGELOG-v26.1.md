# Changelog – v26.1

The v26.1 line focuses on MR calibration, Quest authoring ergonomics, inspection integrity and preparation for an open-source modular architecture.

- Documented the distinction between automated validation and physical Quest acceptance.

The broader application continues to be modularized from the existing LAMP/Quest deployment into reviewable public components.
