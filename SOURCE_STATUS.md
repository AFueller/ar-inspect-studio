# Source publication status

AR Inspect Studio existed as a working LAMP/WebXR application before this public repository was created. The open-source publication is intentionally being performed as a modularization process rather than as an unreviewed dump of deployment files that may contain environment-specific assumptions.

The first public slice contains reusable calibration, geometry, camera and inspection-domain modules plus tests, architecture, security and contribution workflows.

Planned follow-up publication areas include scenario persistence, snapshot/revision handling, reporting, sanitized media examples and the Quest orchestration layer. Each area should arrive with tests and documentation where practical.
